# B Accessories

متجر إكسسوارات حريمي مستقل، بواجهة عربية ولوحة إدارة، مُعد لتطبيق Node.js على Hostinger Business / Cloud.

الإصدار الحالي: **2.1.0**.

## الوظائف

- كتالوج وبحث وفلاتر ومفضلة وشنطة، واقتراح تنسيق القطع.
- طلبات بالدفع عند الاستلام، كوبونات، شحن وتتبع خاص للطلب.
- إدارة المنتجات والأقسام والمخزون والطلبات والكوبونات والإعدادات.
- تقارير الطلبات المسلّمة ومصادر UTM، وتصدير CSV.
- إعدادات GA4 وGoogle Ads وMeta Pixel وConversions API، وكتالوج XML.

## المتطلبات

- Node.js 24 أو أحدث.
- MySQL / MariaDB للإنتاج.
- إعدادات حساب الإدارة ومفتاح تتبع خاص في متغيرات البيئة.

## تجهيز المشروع

```text
npm ci
npm test
npm run build
```

تشغيل محلي بعد تجهيز قاعدة بيانات وإعداد `.env` من `.env.example`:

```text
npm run dev
```

تشغيل نسخة الإنتاج بعد البناء وإضافة متغيرات البيئة:

```text
npm start
```

الاختبارات الافتراضية تستخدم قاعدة SQLite مؤقتة منفصلة. الإنتاج يرفض استخدام SQLite. اختبارات MySQL الإضافية في `tests/` مخصصة لمثيل محلي معزول، وليست قاعدة المتجر الحقيقية.

## Hostinger

راجع [دليل Hostinger بالعربي](HOSTINGER-SETUP-AR.md) للتشغيل، واستيراد قاعدة جديدة، وإعداد حساب الإدارة ومفاتيح الإعلانات.

ملف `database/hostinger.sql` للتأسيس على قاعدة فارغة فقط. يحتوي كتالوج المنتجات الأولي بمخزون صفر واستقبال طلبات مغلق؛ لا يحتوي طلبات تجربة أو حساب دخول افتراضي.

## ترتيب الملفات

| المسار | الاستخدام |
| --- | --- |
| `public/` | واجهة المتجر والإدارة والصور |
| `lib/` | قاعدة البيانات ومنطق الطلبات والربط |
| `server.mjs` | الخادم وواجهات الطلبات |
| `database/` | الهيكل وملف التأسيس |
| `scripts/` | البناء والتأسيس وتجهيز كلمة مرور الإدارة |
| `tests/` | اختبارات منطق المتجر والصلاحيات |

المجلد `dist/` ناتج البناء؛ يُنشأ بالأمر `npm run build` ولا يُحفظ في Git. ملفات ZIP وقواعد المعاينة والأسرار مستبعدة أيضًا.
